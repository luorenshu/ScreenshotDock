# ScreenshotDock 1.0

截图即收纳，随取随用。

## 开始使用

解压整个发布包，双击 `ScreenshotDock.exe`。无需安装 .NET，无需注册账号。

程序启动后在系统托盘运行，顶部没有可见触发块，鼠标移到主显示器最上沿中间区域（约屏幕宽度的三分之一）、稍停约 0.2 秒即可展开截图栏。首次启动会短暂展示截图栏。托盘图标可能被 Windows 收在折叠菜单里，可拖到托盘常用区域。

1. 按 `F1`，或通过托盘菜单选择「立即截图」。
2. 移动鼠标会自动预选所在窗口或支持识别的控件，蓝色边框与尺寸提示跟随区域；单击确认。也可以直接按住拖动，自由框选区域。确认后拖动选区内部可移动，拖动边缘与角点可调整尺寸。
3. 单击确认或框选结束后，选区右下方出现编辑工具栏。可以添加矩形框、椭圆、箭头、画笔、框选马赛克和文字，再完成、复制或保存。
4. 点击「完成」或按 `Enter` 将 PNG 收纳到顶部，默认同时复制到剪贴板。调整选区模式下也可以双击完成。按 `Esc`、点击鼠标右键或 × 取消，小于 2 × 2 像素的选区不会提交。

## 截图标注

自动识别先显示窗口范围，稍停后尝试识别更细的按钮、输入框或内容区。单击前仅预览，确认后移动鼠标不会改变选区；仍可自由移动、调整边缘及标注。有些软件使用自绘界面，没有提供控件边界，此时保留窗口级预选，也可以直接拖动框选。识别仅使用本机窗口与控件信息。

工具栏随选区定位，底部空间不足时自动移到上方，靠近屏幕边缘时保持可见。

界面采用统一蓝色主题，选区使用鲜蓝色加粗边框，角点更大，便于在明亮背景上识别。

截图时使用深色外沿、白色内芯的专用光标，框选、移动、调整大小和文字模式均保持清晰。框选十字中心的小点为实际定位点。光标仅在截图界面生效。

| 操作 | 用法 |
| --- | --- |
| 调整选区 `V` | 拖动内部移动，拖动边缘或角点调整大小。 |
| 矩形 `R` / 椭圆 `O` | 在选区内拖动画框。画好后拖动内部移动位置，拖动四角或四边中点调整大小。 |
| 箭头 `A` | 选择下方样式，再从起点拖向要指示的位置。折线样式按住鼠标沿路线拖动。 |
| 画笔 `B` | 按住鼠标自由绘制。 |
| 马赛克 `M` | 蓝色四格图标，颜色与其他工具一致。在选区内拖动框选要处理的区域，下方可选择颗粒大小 8、16、24、32，默认 16。框选时显示细短白色虚线，选中后显示四角及四边中点共 8 个小方形控制点，拖动区域内可调整位置，拖动控制点可调整大小；也支持多次框选、移除和撤销重做。 |
| 文字 `T` | 点击选区内的位置输入，输入框随内容增长或缩小，到选区边缘自动换行。`Enter` 确认，`Shift+Enter` 换行；再次点击已确认的文字可继续编辑，`Esc` 放弃当前输入或本次修改。 |
| 移除标注 `E` | 点击已有标注将其整项移除；可撤销。 |
| 撤销 / 重做 | 点击对应按钮，或使用 `Ctrl+Z` / `Ctrl+Y`。文字输入时沿用文本框的编辑快捷键。 |
| 保存 `Ctrl+S` | 选择 PNG 文件位置，保存后同时收纳；取消保存对话框可继续编辑。 |
| 贴图（图钉按钮） | 将带标注的图片贴在屏幕上，同时保留到顶部暂存栏。 |
| 复制 `Ctrl+C` | 复制带标注的图片并收纳，即使关闭自动复制也生效。文字输入时 `Ctrl+C` 复制选中的文字，可点击工具栏复制整张图片。 |

选择绘制或文字工具时，工具栏下方显示颜色和线宽，默认线宽为 5，可选择 2、3、5、8；文字工具另外显示字号。可选红、蓝、绿、黄、白和深色，支持中文及多行文字。移动选区时标注跟随，缩小选区会裁去超出部分；重新框选新区域会清空已有标注。所有标注都保留在复制、保存和暂存的图片中，选区边框与工具栏不会出现在最终图片里。

选择箭头工具后，下方显示五种带预览图标的样式：细线、实心、渐尖、空心、折线。渐尖样式的尾部细、靠近箭头处逐渐加粗；空心样式也采用渐尖外形，仅绘制轮廓、内部透明；折线样式保留拖动路线的转折，并在末端自动添加箭头。每根箭头保留独立的样式，切换样式只影响之后绘制的箭头；切换到其他工具再返回，会保留当前选择。全部样式支持颜色、线宽、移除、撤销重做，并保留在复制、保存和暂存的图片中。

输入文字后直接点击保存、复制或完成，会自动确认当前文字。保存出错时显示原因并保留编辑内容。保存文件需要选择暂存目录之外的位置，例如桌面或图片文件夹。

截图编辑状态下，使用文字工具或调整选区工具点击已有文字，可以修改内容、颜色和字号。修改保持原有位置及图层顺序；撤销可恢复修改前的文字，重做可恢复修改后的文字。清空文字后确认会移除该文字标注，也可撤销。点击保存、复制、贴图或完成都会确认尚未提交的修改。

马赛克只处理框选的矩形区域，不改变区域外的像素；颗粒大小影响之后框选的区域。在马赛克或调整选区工具下，可以按住已有马赛克区域拖动，大小和颗粒强度保持不变，移动到截图边缘时自动限制位置；移动后原位置恢复原始截图，新位置实时应用马赛克。选中区域后，可拖动四角或四边中点的小方形控制点调整马赛克范围；调整范围时颗粒强度保持不变，到截图边缘时限制范围，最小尺寸为 1 个物理像素。松开后一次 Ctrl+Z 可撤销整次移动或大小调整，拖动时按 Esc 只放弃当前调整。白色虚线框及小方形控制点仅用于编辑，整体截图选区继续使用蓝色边框；两种边框都不会进入导出图片。预览与导出共用相同的像素化结果，保存、复制、贴图及暂存图片均包含马赛克。

矩形和圆形（椭圆）画好后会自动选中，显示细白色虚线边界及八个控制点。使用对应的形状工具，或切换到「调整选区」后点击已有形状，即可再次编辑：拖动内部移动位置，拖动四角同时调整宽高，拖动四边中点只调整对应边。调整时保留颜色和线宽，范围限制在截图区域内，整体截图选区保持不变。重叠形状选择当前工具可编辑的最上层；圆形外接矩形的空白角落不会触发移动。

每次松开后，`Ctrl+Z` 撤销整次形状移动或大小调整，`Ctrl+Y` 重做。拖动中按 `Esc` 仅放弃当前调整并继续截图；失去鼠标捕获也会放弃未完成的调整。保存、复制、贴图或完成时确认当前调整，导出图片保留调整后的形状，虚线及控制点不会进入图片内容。

截图状态下点击鼠标右键会直接退出整次截图，包括尚未框选、正在绘制、文字输入框和工具栏上。当前选区与标注不会保存，也不会进入暂存栏；文字输入时右键取消截图，`Esc` 仍只取消当前文字。

## 桌面贴图

框选和标注完成后，按 `F3` 或点击截图工具栏靠近保存按钮的图钉，即可退出截图并把图片置顶贴在原来选区的位置。尚未确认的文字会一起保留到图片中。

截图完成后，也可以按 `F3` 将最近一张暂存截图贴到屏幕；重复按键可贴出多张独立图片。本次截图仍使用原来的选区位置；重启软件后，从暂存库恢复的最近图片显示在鼠标所在屏幕中央，尺寸过大时自动缩小到可见范围。尚未选择截图区域时，贴图快捷键不会结束截图。F1 与 F3 均可在设置中自定义。

可以同时贴多张图片。拖动图片内部调整位置，拖动四条边或四个角调整显示大小，鼠标靠近边缘时会显示对应的缩放光标。缩放保持图片比例，边缘拖动固定对侧边并从另一方向居中调整，四角拖动固定对角；最短边至少为 32 DIP。缩放仅影响屏幕上的贴图，暂存原图的分辨率不变，每张贴图可独立调整。

未选中的贴图在图片边缘外侧显示淡白色柔和阴影，点击某张图片后变为蓝色阴影；按 `Esc` 只移除当前选中的贴图，其他贴图继续显示。贴图的阴影不会进入图片内容，移除贴图也不会删除顶部暂存栏中的截图。

再次截图时，已有贴图会暂时隐藏，完成或取消截图后恢复，避免截进新图片。退出程序时关闭全部贴图，下次启动不会自动恢复贴图位置；对应截图仍按暂存设置保留。清理暂存图片不会关闭当前已经显示的贴图。

## 再次使用截图

- 鼠标移到主显示器最上沿中间区域，稍停约 0.2 秒即可展开；触发范围居中占屏幕宽度约三分之一，两侧不触发，完全透明且不挡住下方窗口的点击。展开后的截图栏仍横跨整个屏幕；移出顶部展开热区后，经过约 0.1 秒防抖即开始动画收起。展开热区覆盖整个截图栏，包括透明空白处。
- 单击卡片复制，双击打开大图预览。
- 将卡片拖到文件夹、聊天窗口、网页上传区或支持文件拖放的应用。
- 右键提供复制、预览、另存为、移除暂存。
- 单击卡片右上角的 × 删除暂存图片；右下方的「清空暂存」会弹出二次确认，仅点击「确认清空」后删除全部暂存图片。取消或关闭确认窗口会保留图片。
- 图片较多时，用滚轮横向浏览卡片；整个顶部热区都支持滚动，包括图片之间和下方的透明空白处，不显示滚动条。
- 截屏、锁定和设置位于右上方，清空暂存位于右下方，右上角没有收起箭头。单击锁定按钮保持展开，再次单击取消锁定，移出热区后自动收起。

未锁定时，鼠标在卡片与透明空白之间移动都会保持展开；自动回收途中移回热区会停止回收并重新展开。截图后首次展示会短暂保持，鼠标进入热区后再移出便立即按上述规则收起。拖拽分享和右键菜单操作期间暂停自动收起。

热区内的滚轮只浏览截图，不会滚动下方窗口，即使截图不足一屏或已滚到两端也一样。鼠标移出热区或截图栏隐藏后，恢复正常滚动。透明空白处的点击仍可操作下方窗口，设置和预览窗口保持各自的滚轮操作。

不同应用的拖放支持有差异。拖放不成功时，可以单击复制后粘贴，或右键另存为再上传。向以管理员身份运行的应用拖放，可能受到 Windows 权限级别限制。

## 设置与托盘

在截图栏齿轮按钮或托盘菜单打开设置。“截图快捷键”默认 F1，“贴图快捷键”默认 F3；分别点击输入框后按下想使用的按键，支持 F1、F2 等单键，也支持 Ctrl、Alt、Shift、Win 与按键组合。各自的“恢复默认”只重置对应快捷键。两个快捷键不能相同；保存时检测实际系统冲突，冲突或保存失败时保留之前可用的设置。支持 F1–F11、字母、数字、PrintScreen；F12 为 Windows 调试器保留键，不接受。打开设置期间暂时暂停两键，关闭后恢复，截图栏与托盘按钮仍可使用。

升级后旧默认 Ctrl + Shift + A 会改为 F1，之前自定义的其他截图键保持原样。新版本中也可以重新设为 Ctrl + Shift + A 并保存。

展开的截图栏采用透明晾衣绳样式，横跨主显示器的完整宽度：挂绳和卡片出现时从屏幕顶部落下，轻微回弹后停稳，动画约 0.42 秒；移出热区自动收起时向上回收，动画约 0.28 秒。顶部同时淡入一层明显的深色渐变阴影，越往下越浅，底部沿两侧略高、中间轻轻下沉的弧线自然消散到透明，收起时同步淡出。收起过程中重新展开会平滑返回。卡片以夹子挂在弧形绳索上，轻微倾斜，复制成功时在对应卡片下方显示「已复制」。操作按钮位于右侧；操作提示、状态消息和空状态说明居中显示在挂绳与屏幕顶部之间。鼠标移到卡片后显示移除按钮和图片尺寸。渐变下仍能看见桌面内容，空白处的点击可穿透到底下的窗口；鼠标离开展开区域后自动收起。Windows 关闭界面动画时直接展开或收起。截图和全屏避让时，挂绳与渐变一起隐藏。

可以修改暂存数量（1–1000）、保留天数（1–365）、自动清理、自动复制、截图后展开及全屏避让。默认最多 100 张，保留 7 天。开启自动清理时，启动、截图完成、修改设置以及每五分钟执行清理。关闭自动清理后，数量与期限限制暂停应用。

设置页采用紧凑双列布局，直接从截图快捷键开始，顶部标语和下方本地存储说明区域已移除。所有选项直接显示，没有滚动条，也没有左下角托盘运行提示。「开机启动」勾选后立即生效，取消勾选立即关闭，不需要点击「保存设置」；关闭设置窗口不会撤回该开关。其他偏好仍通过「保存设置」应用。开机启动会在当前用户登录 Windows 后于托盘运行。移动软件位置后，请取消并重新勾选该选项以更新路径。

托盘「暂停快捷键」会释放该组合键；恢复时重新检测是否被其他软件占用。截图栏按钮和托盘「立即截图」仍可使用。关闭设置或预览窗口不会退出程序；退出请使用托盘菜单。

## 本地数据

```
%LOCALAPPDATA%\ScreenshotDock\
  screenshots\      原始 PNG（程序管理的暂存文件）
  thumbnails\       缩略图
  screenshots.json  暂存索引及备份
  settings.json     配置及备份
  logs\             最多保留七个日志文件
```

重启后恢复未过期的图片。相同 PNG 自动去重并移到最前。另存为的永久副本需要放在暂存目录之外，删除和清理不会删除这些副本。不要把自己的文件放进暂存目录。

图片和配置只存本机。程序不上传截图、不读取其他应用的剪贴板图片。运行核心功能不需要网络。

## 当前版本范围

本版实现 PRD V1.0，并加入截图标注工具栏和多图桌面贴图：区域截图、矩形与椭圆、箭头、画笔、文字、撤销重做、顶部暂存、复制、文件拖放、预览、保存、贴图、设置与托盘。OCR、长截图、云同步不在本版范围。

Windows 10 / 11 x64。使用 .NET 10 WPF、自包含发布。混合 DPI、多屏排列及微信/QQ/设计软件拖放，仍需要在对应真实设备与应用中验收。受系统或应用保护的画面可能显示黑色或不可采集；不支持安全桌面和 DRM 绕过。
